# Studio — Elad Amsalem Studio

**שם עבודה:** Studio. פלטפורמה ואפליקציה לאמנים חזותיים, בנויה כמו Spotify: לכל אמן פרופיל, תערוכות כמו אלבומים, עבודות כמו סינגלים, ותערוכה דיגיטלית אחת שתמיד פתוחה.

- `index.html` — עמוד החזון: חזון, מבנה, טיזרים של מסכי האפליקציה, חדר תלת־ממדי חי עם העבודות של "טקס", מחקר מתחרים, רעיונות לשם ומפת דרכים.
- `teaser.src.html` — המקור של העמוד. אחרי עריכה מריצים מהשורש של הריפו: `python3 studio/build.py`, שמטמיע את העבודות מ־`content/works.json`.

## החזון בקצרה

1. **תמיד מוצג** — לכל אמן יש בכל רגע תערוכה דיגיטלית אחת פתוחה, בחלל תלת־ממדי שהוא בוחר. הקודמות עוברות לארכיון.
2. **רק עבודות אמיתיות** — כל עבודה שמוצגת קיימת פיזית: מידות, טכניקה, שנה, מיקום.
3. **הדיגיטלי מוביל לפיזי** — עוקבים מקבלים התראות על פתיחות, ובכל עיר רואים אילו אמנים מציגים בה.
4. **בהמשך: מגזין** — הפלטפורמה אוצרת תערוכות קבוצתיות דיגיטליות, כמו גיליונות.

| Spotify | Studio |
|---|---|
| Artist profile | פרופיל אמן |
| Now playing | עכשיו מוצג (התערוכה הדיגיטלית החיה) |
| Album | תערוכה |
| Single | עבודה |
| Discography | ארכיון לפי שנים |
| Concerts | תערוכות פיזיות על מפה |
| Editorial playlist | תערוכה אוצרותית / מגזין |
| Spotify for Artists | Studio לאמנים |

## מחקר — מה קיים

החלקים קיימים בנפרד, אף אחד לא מחבר את כולם:

- **Artsy** — מעקב אחרי אמנים ותערוכות לפי עיר, אבל בנוי סביב גלריות ומכירה.
- **Artland** — סיורים תלת־ממדיים בתערוכות של גלריות ו־AR. הלקוח הוא הגלריה.
- **Kunstmatrix, Artsteps** — כלים לבניית תערוכות תלת־ממדיות. בלי קהל ובלי גילוי.
- **Vortic** — VR/AR לגלריות ואספנים.
- **Ocula** — מגזין ורשת גלריות.
- **ArtRabbit** — רשימות תערוכות, מפות, סיורי הליכה. בלי פרופיל אמן.
- **Smartify, Bloomberg Connects** — מדריכים למוזיאונים.
- **Saatchi Art, Singulart** — מרקטפלייס, לא תערוכה.
- **Instagram, Cara, Behance** — פיד ופורטפוליו, בלי הקשר של חלל או מיקום.

**הפער:** פלטפורמה שבה האמן במרכז, כמו המוזיקאי ב־Spotify, והגלריה היא רק אחד המקומות שבהם הוא מציג.

## מפת דרכים

0. חזון, מחקר וטיזרים (עכשיו)
1. אב־טיפוס על אמן אחד: הפרופיל של אלעד, ארכיון, ותערוכה דיגיטלית שעובדת בנייד
2. 10–20 אמנים מוזמנים, עורך תערוכות פשוט, עוקבים
3. עיר ומפה, תערוכות פיזיות, התראות
4. מגזין, מכירות, אפליקציה ל־iOS ו־Android
