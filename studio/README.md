# Studio — אלעד אמסלם סטודיו

**שם עבודה:** Studio. פלטפורמה ואפליקציה לאמנים חזותיים, בנויה כמו Spotify: לכל אמן פרופיל, תערוכות כמו אלבומים, עבודות כמו שירים, ותערוכה אחת שתמיד פתוחה ותלויה בקנה מידה אמיתי.

**שפה:** תוכן ועיצוב האפליקציה באנגלית. המצגות, ההסברים והחזון בעברית.

## מה יש כאן

| קובץ | מה זה |
|---|---|
| `PROPOSAL.md` | ההצעה המלאה, v3: חזון, מסכים, אישורים, סטנדרט איכות, חלל, טכנולוגיה, עלויות, מפת דרכים |
| `REVIEW.md` | יומן הבדיקה העצמית: שני סבבים, מה נמצא ומה השתנה |
| `research/RESEARCH.md` | דוח המחקר: מתחרים, לקחים, איכות, שוק ותשתית, עם מקורות |
| `research/cost_model.py` | מודל עלויות הענן. כל הנחה היא קבוע שאפשר לשנות ולהריץ מחדש |
| `proposal/` | דף ההצעה האינטראקטיבי: חלל תלת־ממדי בקנה מידה אמיתי וכל מסכי האפליקציה (באנגלית) |
| `proposal/space.js` | בונה החלל המשותף (הקיר, התאורה, התלייה בקנה מידה), שמשמש גם את הדף וגם את הטיזר |
| `proposal/screens/` | צילומי מסך של מסכי האפליקציה |
| `teaser/` | טיזר של 40 שניות: דף שמנגן חי, וקובץ `studio-teaser.mp4` |
| `index.html` | עמוד החזון הראשון (טיוטה מוקדמת, בעברית) |
| `app/` | אב הטיפוס של האפליקציה (צד המשתמש) |
| `app/space/pipeline/` | **מנגנון החללים**: מקבל צילומי הצבה של תערוכה ואת העבודות (תמונה + מידה) ובונה לבד חלל תלת־ממדי מדוד. פירוט למטה |
| `app/space/space.js` | מציג החלל: הליכה חופשית (ג'ויסטיק / WASD / הטיית הטלפון / משקפי VR), מעבר בין עבודות, ומבט מנקודת הצילום של כל תמונה |
| `app/data/spaces/<תערוכה>.json` | החלל שהמנגנון בנה, והטקסטורות בתיקייה באותו שם |
| `app/data/spaces/<תערוכה>.report.md` | דוח בעברית: מה זוהה, מה נמדד, מה לבדוק |
| `research/SPACES.md` | מחקר: מי עושה את החללים הדיגיטליים הכי ריאליסטיים ומה זה אומר ל־Studio |

## בנייה

מהשורש של המאגר:

```
python3 studio/proposal/build.py   # בונה את studio/proposal/index.html
python3 studio/teaser/build.py     # בונה את studio/teaser/index.html
python3 studio/research/cost_model.py
python3 -m studio.app.space.pipeline       # בונה מחדש את החללים של כל התערוכות (או: ... pipeline ritual)
python3 studio/app/build.py                # עותק עצמאי לצפייה: studio/app/preview.html
python3 studio/app/build.py --out DIR      # אותו דבר כדף + קבצי תמונה, לגרסה באיכות מלאה
```

## מנגנון החללים

לכל תערוכה, בלי עבודה ידנית:

1. **זיהוי:** מאתר כל עבודה בכל צילום, לפי השוואה לתמונה האיכותית שלה. העבודה מושווית גם כפי שהיא נראית בזווית, כדי למצוא עבודות על קיר צדדי.
2. **מדידה:** כל עבודה היא סרגל. כל המצלמות וכל העבודות נפתרות יחד (bundle adjustment), בהנחות של גלריה: קירות בזווית ישרה, עבודות ישרות, והמידות הרשומות כמעט נכונות. המידה שנמדדה בפועל נכנסת לדוח.
3. **החדר:** הרצפה נמצאת בגובה שבו הצילומים מסכימים עליה. הקירות נקבעים לפי העבודות שתלויות עליהם, והתקרה לפי הקו שבו הקירות נגמרים. פתח מזוהה כשרואים בו את הרצפה ממשיכה.
4. **האור האמיתי:** הצילומים מוקרנים על הקירות והתקרה. מכל נקודה נלקח הצילום שרואה אותה הכי טוב, אחרי השוואת חשיפה בין הצילומים. ברצפה נלקחים המרקם שלה והאור עליה, וההשתקפויות מחושבות בזמן אמת.
5. **העבודות:** מוצגות מהתמונה המלאה, עם עובי וצדדים. האור שנפל עליהן נמדד בהשוואה בין הצילום לתמונה, ועליהן ברק לכה עדין שזז כשזזים.

**ריצה אוטומטית:** `.github/workflows/studio-spaces.yml` מריץ את המנגנון בכל שינוי בעבודות, בתערוכות או בתמונות, ושומר את התוצאה.

**מדידה ידנית (לא חובה):** אם יש מספרים ממד לייזר, כותבים אותם ב־`app/data/spaces/<תערוכה>.overrides.json`, והם גוברים על החישוב:

```
{"height": 3.82, "work_centre_height": {"Gathering": 1.40}, "walls": {"x1": 6.10}}
```

שני סקריפטי הבנייה מטמיעים את העבודות מ־`content/works.json`, ובודקים את המידה של כל עבודה מול יחס הגובה־רוחב של התמונה שלה.
