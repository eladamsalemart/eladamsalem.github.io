# הסוכן מהנייד

שתי דרכים, ושתיהן בטאב "סוכן" בלוח הבקרה (`#/admin/agent`). הכפתורים למעלה בוחרים ביניהן.

## 1. ענן (עובד מכל מקום, גם כשהמחשב כבוי)

הסוכן בענן (`studio/supabase/functions/agent-chat`) מדבר איתך בעברית, מדייק, ובסוף מגיש בקשה מדויקת למפתחים (`change_requests`),
והמפתחים (סשנים של Claude) מבצעים. הוא לא עורך קוד בעצמו.

**חיבור, פעם אחת (רק אתה יכול):**
1. מפתח API של Anthropic (console.anthropic.com → API keys). עולה כסף לפי שימוש, ואפשר להגביל תקציב חודשי שם.
2. ב־GitHub: המאגר → Settings → Secrets and variables → Actions → הסוד `ANTHROPIC_API_KEY` (הוא קיים וריק) → Update → להדביק את המפתח.
3. להריץ את "Supabase functions" (Actions → Run workflow), או שהפרסום הבא יעשה את זה. הוא מעתיק את המפתח לפונקציה.
המפתח לא נשלח בשיחה ולא נכתב בקוד.

## 2. המחשב שלך (עורך קוד אמיתי)

במחשב: `studio\agent\start-agent.cmd` (בפעם הראשונה: `claude` ואז `/login` ב־Claude Code, ולהדביק את ה־Token שבחלון בטאב הסוכן).

**מהנייד** צריך כתובת של המחשב ברשת פרטית (Tailscale, חינם):
1. להתקין Tailscale במחשב ובנייד ולהתחבר לאותו חשבון (tailscale.com/download).
2. במחשב, ב־PowerShell: `tailscale serve --bg --https=8799 http://127.0.0.1:8799`
3. הכתובת תופיע (`https://<שם-המחשב>.<שם-הרשת>.ts.net:8799`). להדביק אותה בטאב הסוכן, במסך "המחשב לא מחובר", ולשמור.
הגשר נשאר פתוח רק למחשב עצמו; Tailscale מעביר אליו רק ממכשירים שלך. המחשב צריך להיות דולק ו־`start-agent.cmd` פתוח.
